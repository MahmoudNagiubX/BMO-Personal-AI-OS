# Phase 11 - Room / Multi-Device Voice

## Status

`NOT_STARTED`. This document records the deferred boundary established by
ADR-0010; it is not an implementation task for Phase 10.

## Deferred scope

Phase 11 may later evaluate distributed room microphones, multiple room
speakers, room-presence routing, remote room nodes, ESP32/Pi room hardware,
far-field microphone topology, whole-home voice handoff, multi-device session
routing, and room-level wake-word deployment.

Any such work requires a separate owner authorization, physical/privacy
acceptance, and architecture review. It must preserve the single-device
JARVIS Voice Core, central identity, permissions, approvals, audit, and
no-retention defaults.

## Explicit non-start

Phase 10 does not implement or deploy room/multi-device voice. No room node,
distributed microphone, room speaker, Home Assistant/MQTT voice path, public
voice endpoint, or room hardware is created by this phase.
